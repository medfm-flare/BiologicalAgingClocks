# TraMA
## Code used to train TraMA in HRS and needed to reproduce TraMA in other data.

To create TraMA in your data:
Download and unzip the making_trama.zip folder.
Follow directions in read_me.txt.
The R markdown file replication.Rmd is used to calculate TraMA in your data.
