- **Zhang10** - Zhang, Y. et al. *Nat. Commun.* 8, 14617 (2017). Implemented as `Zhang_10`.

Also includes implementations of Horvath, Hannum, PhenoAge (Levine), PC-Clocks,
DNAmTL, and others - see package docs for the full clock list.

Direct copy at the commit above, git history stripped. To update, re-clone
upstream at a newer commit and replace this directory.
